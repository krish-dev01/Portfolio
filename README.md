# Krishnaraj's portfolio

This is a local design preview. Open `index.html` in a browser, or run `python -m http.server 8000` in this directory and visit `http://localhost:8000`. No build step, scripts, analytics or external assets are required.

This variant uses the existing skills and education and a dark editorial layout without a portrait. The Projects section is intentionally absent for this review. The earlier project-bearing preview is unchanged. The Anton font is distributed with its license in `assets/Anton-OFL.txt`.
